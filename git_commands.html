Основні команди Git

1. Ініціалізація та клонування

git init
git clone https://github.com/user/repo.git
git status

2. Робота з файлами та комітами

git add .
git add filename.html
git commit -m "Повідомлення коміту"
git commit -am "Повідомлення"
git log --oneline
git log

3. Робота з гілками

git branch
git branch назва_гілки
git checkout назва_гілки
git checkout -b назва_гілки
git merge назва_гілки

4. Робота з віддаленим репозиторієм

git remote add origin URL
git push origin develop
git pull
git push -u origin develop

5. Інші корисні команди

git checkout -- filename
git reset
git stash
git diff
